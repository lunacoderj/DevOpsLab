What is Git?

Git is a distributed version control system used to track code changes.

What is GitHub?

GitHub is a cloud platform where developers store and manage Git repositories.

Basic Git Commands

Initialize Git

git init

Add Files

git add .

Commit Changes

git commit -m "First Commit"

Connect Remote Repo

git remote add origin REPO_URL

Push to GitHub

git push -u origin main

Live Tutorial: Push Local Project to GitHub

Step 1: Create Repository on GitHub

Login to GitHub → Click "+" → New Repository → Enter repository name → Create Repository.

Step 2: Open Project in VS Code

Open your local project folder in VS Code.

Step 3: Open Terminal

In VS Code go to:

Terminal → New Terminal

Step 4: Initialize Git

git init

Step 5: Add Files

git add .

Step 6: Commit Files

git commit -m "Initial Commit"

Step 7: Connect GitHub Repository

git remote add origin https://github.com/username/repository.git

Step 8: Push Files to GitHub

git push -u origin main
